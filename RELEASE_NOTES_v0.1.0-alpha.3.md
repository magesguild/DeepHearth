# Deep Hearth 0.1.0 Alpha 3

Deep Hearth Alpha 3 is a local reference-body update from Basin Game Studios.
The published Alpha 2 release remains the public baseline; this release carries
the next constitutional layer on the `death-and-return` branch.

## T-Stop and State Closure

Alpha 3 adds a shared terminal constitution across the book:

- completion, Rest, refusal, unavailability, interruption, recovery, surrender,
  incapacitation, and death remain distinct;
- zero Integrity does not automatically kill a character;
- there is no generic death-saving throw;
- Prone and named injuries are recoverable physical states;
- State Capsules preserve terminal state, recovery paths, and resume conditions;
- combat, ecology, encounters, familiars, organs, magic, growth, land, and
  persistence use declared T-Stop sets;
- battle grids and figures are explicit primary spatial materials, with cards and
  ledgers remaining optional state and witness surfaces.

## State-Closure Improvements

- combat cycle registers reset at round boundaries unless a named condition says
  otherwise;
- party registers have alpha ranges and zero-state behavior;
- State Capsule restore rejects stale or incompatible branches safely;
- magic and host organs settle external results before updating Basin state;
- growth, Reserve, land access, care, beast clocks, and scenario clocks have
  explicit defaults or declared local overrides;
- the technical alpha now documents the future Player Handbook, GM's Guide, and
  optional Bestiary publication surfaces.

This remains an alpha reference body and has not entered external playtesting.
Playtesting remains the gate into beta, not a requirement for every alpha
revision.
