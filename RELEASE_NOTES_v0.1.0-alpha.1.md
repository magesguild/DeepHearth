# Deep Hearth 0.1.0 Alpha 1

Deep Hearth is a public alpha from **Basin Game Studios**: an open-source,
tactile tabletop computer about characters, parties, worlds, cards, dice,
familiars, machines, land, memory, and return.

This release includes:

- the complete golden-seed reference body;
- character creation and four starting species;
- dice ecology, computational minigames, economy, magic, and combat;
- Grapple as Hold Relation and the first armed exchange;
- the Familiar System and Hearth REPL;
- `KINDLE-RAT` and `READ-COLONY` optional organs;
- The Tableau as a generic card substrate;
- alignment, land palettes, Growth Rings, and loot packets;
- GM State Deck save/restore and app adapter contracts;
- glossary, reader index, and printable table tools.

This is an alpha and needs playtesting. Please use the [GitHub issue
tracker](https://github.com/magesguild/DeepHearth/issues) for unclear rules,
broken procedures, awkward forms, scenario reports, and unexpected emergent
behavior.

Deep Hearth is released under the [MIT License](LICENSE). When the system is
finalized, Basin Game Studios plans to publish affordable game books, campaign
books, and prepared worlds alongside the source.
