# Deep Hearth

**Basin Game Studios**

## A small world that can return

Deep Hearth is a small, bounded reference implementation for Basin.

It is not the final universe. It is the living reference body: a bounded,
playable ecology in which the rules can be understood completely, run by hand,
replayed, repaired, and extended through new words and organisms.

The purpose of the reference body is practical. We will not guess the bare-metal
candidate from abstraction alone. We will play Deep Hearth, observe what the
table actually needs, and distill the smallest Basin kernel that remains a game,
a computer, and a world that can return.

## The first promise

The table is a physical state machine operated by people, objects, procedures,
resources, and memory:

```text
state
-> input
-> legal transition
-> witnessed output
-> Rest or continuation
```

The player is not outside the machine. The player supplies intention, selection,
interpretation, and care. The objects supply persistent state and constrained
possibility.

## Alpha 4: Responsive Neighborhood Alpha

The next alpha is called the **Responsive Neighborhood Alpha** because it is the
first Alpha 4 body in which a populated place can answer back through people,
jobs, relationships, knowledge, community, ecology, terrain, care, and memory.

It is deliberately one bounded vertical slice, not a complete city simulation:

```text
Waterdeep neighborhood
-> household
-> baker job
-> guild or institution
-> shared resource
-> ecological pressure
-> terrain problem
-> knowledge boundary
-> player intervention
-> persistent consequence
-> Rest
-> return
```

We are building the systems to support a larger world iteratively. This pass
makes the world more inhabited without pretending that every NPC, market,
language, or region must be continuously simulated. A later pass will tighten
numbers and calculation procedures; this pass preserves the intended spirit.

## What this document is

This book is a working reference for one Basin ruleset that can support:

- a small solo or cooperative game;
- roleplaying campaigns;
- pure calculation exercises;
- living worlds with persistent consequences;
- later digital and online implementations.

The open rules remain separate from any private setting substrate. A Forgotten
Realms campaign may be used privately as a populated world, but Deep Hearth's
public mechanics must remain original and must respect Open Game Content,
Product Identity, trademark, copyright, and attribution boundaries.

Deep Hearth can also sit beside an existing campaign module as a conversion
layer. The host module supplies its setting, maps, characters, and premise;
Deep Hearth supplies job stamps, body projections, relationships, ecology,
T-Stops, witnesses, and return state. The Alpha 4 Responsive Neighborhood is the
first authored slice of that larger conversion path.

## How to read it

Begin with the core action. Then read the ecology: character membranes, party
organisms, encounters, and worlds. After that, read memory and return. The alpha
boundary names what must become playable before the reference body grows larger.

The design talisman is simple:

> Every class has a membrane. Every party develops a membrane. The world is the
> garden in which the party grows.

> Do not roll to discover whether a character may act. Let deterministic physics
> answer what is known; let the die enter only where uncertainty can change the
> future.

> Inventory is memory. Magic is a macro-instruction. Combat is pressure and
> response. Rest is a valid result.
