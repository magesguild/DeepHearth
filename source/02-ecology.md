# The Ecology

## Classes as species

A class is a functional species in the party ecosystem. It is not a rank and not
a command to behave in one way. It is a membrane: a characteristic way of
sensing, contributing, spending, protecting, and changing the world.

The first alpha species are:

| Species | Ecological niche |
| --- | --- |
| Alchemist | Metabolism, transformation, portable laboratory |
| Bastion | Force, structure, boundary, load-bearing stability |
| Wayfinder | Sensing, routing, precision, and path memory |
| Hearthkeeper | Repair, homeostasis, recovery, and safe Rest |

Each character declares what they sense, contribute, consume, protect, refuse,
and how they recover.

## The party organism

The party is a multicellular organism whose cells remain distinct, conscious,
and consenting while contributing to a shared body.

| Register | Meaning |
| --- | --- |
| Cohesion | Ability to coordinate and exchange signals |
| Reserve | Shared supplies, energy, time, and recovery |
| Integrity | Capacity to remain a functioning group under pressure |
| Memory | Maps, promises, discoveries, and unresolved consequences |

The party is not a hive mind. A character may refuse, disagree, hold private
memory, leave the formation, or ask the group to pause.

Collective action follows this shape:

```text
party intent
-> contributions
-> one witnessed transition
-> changed world and character state
```

The party grows stronger not by making every cell identical, but by making their
differences interoperable.

## Inventory as memory

Inventory is an active memory hierarchy:

| Layer | Role |
| --- | --- |
| Ready slots | Active registers and organs |
| Personal pack | Working memory |
| Shared party pack | Shared memory |
| Cache or stash | Persistent archive |
| Lost or spent items | Unavailable state |

The player decides what deserves immediate access. Inventory becomes interesting
when access, transfer, combination, and loss change what the party can do.

## Combat and magic

Combat is a live program, not only a damage exchange:

```text
intent
-> position and resource choice
-> pressure
-> response
-> consequence
-> changed state
-> Rest or next exchange
```

A player may injure, protect, restrain, escape, interrupt a ritual, rescue a
cell, change terrain, break morale, or force a retreat. Damage is one possible
output.

Magic is a macro-instruction with inputs, cost, target, timing, duration, state
effect, interruption conditions, and residue. Spell families include Signal,
Query, Transform, Summon, Ward, Repair, Traverse, Bind, Disrupt, and Seed.

## Encounters as programs

A Game Master designs an encounter as a program with laws, not a script with one
permitted ending.

```text
initial state
physical laws
resources
sensors
hidden state
inhabitant goals
refusal conditions
entropy packets
legal response space
failure states
Rest condition
persistent traces
```

Hard law includes timing, resource costs, movement, boundaries, sensing,
crossings, damage, recovery, and conservation of declared resources. Soft ecology
includes what an inhabitant wants, fears, remembers, prefers, refuses, bargains
for, protects, or becomes.

## The garden

The world is not scenery behind the party. It is the garden substrate in which
the party grows.

```text
world ecology
    -> region ecology
        -> dungeon or settlement ecology
            -> party membrane
                -> character membranes
                    -> class membranes
```

Every layer has local state, resources, clocks, boundaries, signals, memory, and
ways to recover.
