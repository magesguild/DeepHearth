# Deep Hearth Alpha

## The golden seed

Deep Hearth alpha does not need to contain the whole universe. It needs a small,
complete kernel that a group can run without the designer sitting at the table.

The smallest seed is:

```text
one character
one question
one resource
one meaningful uncertainty
one changed state
one witnessed return
```

Every alpha interaction also declares a small **T-Stop set**. The seed teaches
that completion, refusal, interruption, recovery, and death are different
answers, and that no die forces a player or character to continue.

## Pure Compute

Begin with one character, one challenge, one resource, and one output:

```text
Input: one exploration question
State: one capability and one resource reserve
Operation: d20 + capability
Threshold: one Demand
Output: changed state
Rest: record the result and stop
```

The Pure Compute stop record is:

```text
status: COMPLETE / REFUSED / INTERRUPTED / INVALID / REST
reason: ______________________
last legal state: ____________
resume condition: ____________
witness: _____________________
```

This teaches state, threshold, resource expenditure, consequence, and witness
without requiring a campaign or combat.

## Alpha completion boundary

The first complete guide must settle capacities, Demand values, outcome bands,
resource costs, conditions, action timing, Rest, deterministic versus uncertain
actions, and when a die is rolled.

It must let a new group:

- create one character;
- choose or build a class membrane;
- run Pure Compute;
- play one ecological encounter;
- resolve combat;
- use one spell;
- manage inventory;
- save and load a State Capsule;
- create one new class or monster from a template;
- choose a legal T-Stop in every interaction;
- improvise without breaking the world's physics.

## First scenarios

### The Threshold Room

Pure Compute. One stateful challenge, one resource reserve, one physical die
input, and a room that changes in response to every choice.

### The Lantern Orchard

An ecological encounter with a living local system, competing needs, hidden
state, and a Rest condition that is not identical to victory.

### The First Descent

A private Forgotten Realms campaign opening beneath Waterdeep, where the rules
remain Basin's and the populated setting layer remains bounded and separate.

## First ecology

The first bestiary should include:

- a Memory Myconid Choir;
- a Hook Horror Nest;
- the Otyugh of the Old Cistern;
- a Lantern Moth Swarm;
- an Archive Warden;
- one hostile faction agent;
- one environmental hazard.

## Life cycle

The alpha should feel like a small golden seed with a complete life cycle:

```text
create
-> act
-> spend
-> remember
-> change
-> choose a legal terminal
-> Rest
-> return
```
