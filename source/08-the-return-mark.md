# The Return Mark

## An inheritance, not a command

The Threshold Room has a far side now. Something was there before the Alchemist,
but the room does not turn the previous visitor into a villain, a corpse, or a
prophecy.

The room remembers only this:

```text
a body carried light
a cost was paid
a crossing occurred
a return was intended
the return is unknown
```

The visitor's identity remains open. The group may discover it later, inherit
the question, or decide that the unknown person deserves to remain unknown.

## This minigame

```text
question: what can be inherited without claiming another life?
initial state: Return Mark and empty vial on far side
participants: present body, prior trace, and room memory
moves: inspect, carry, leave, refuse, ask, Rest
apparatus: Mark, vial, witness card, inventory
uncertainty: prior identity and return outcome remain unknown
exit: inherited, declined, carried, or Rest
T-Stop set: COMPLETE / REFUSED / UNKNOWN / REST
```

The inheritance minigame computes provenance and custody. It does not compute
the absent visitor's private motive.

## Dice habitat

```text
primary die: none
support dice: none
persistent registers: object location and lineage
entropy budget: none for inspection or refusal
witness: Mark, vial, inventory, and State Capsule
```

The absence of a die is part of the design. The room already knows that the
objects are present; uncertainty concerns meaning and identity, not visibility.

## The mark

On the far side, a small Return Mark has been made in the stone from whatever
material the place provides. It carries three public facts:

```text
prior crossing witnessed
route back toward the threshold
unfinished invitation
```

Beside it rests an empty vial. Its only inscription is:

> Carry only what can come home.

Neither object is treasure. The Return Mark is not a key. The vial does not grant
permission or power. They are evidence that someone before the player understood
that crossing is only half of a journey.

## Finding the inheritance

If the Alchemist achieved strong success, the hidden handhold already revealed
the alcove containing the Mark and vial.

Otherwise, the player may inspect the far side. Inspection is deterministic: the
room's state already contains the alcove. The player does not roll to discover
whether the world is allowed to remember.

```text
inspect far side
-> find Return Mark
-> find empty vial
-> add prior crossing to public memory
-> offer a choice
```

## The choice

The player may:

- carry the Return Mark;
- leave the Return Mark in place;
- carry the empty vial;
- leave the empty vial in place;
- record the inheritance and Rest;
- refuse to touch either object;
- ask what kind of return the prior visitor intended.

No option is secretly correct. Touching is not consent to finish another person's
story. Refusal is not indifference. Leaving an object where it was found may be
the most respectful act available.

## State changes

When the Mark is found, add this public memory:

```text
Prior visitor: witnessed, identity unknown
Prior crossing: completed
Return intention: witnessed, outcome unknown
Return Mark: present on far side
Empty vial: present on far side
Open question: can a return be completed without claiming the visitor's life?
```

If the player carries an object, update inventory. If the player leaves it, the
far side retains the object and the return path retains its marker.

The inherited object has provenance but no automatic claim on the player. Its
economic state is:

```text
source: prior visitor
current holder: none / character / party
offered: yes / no
boundary: do not annex the absent visitor's story
future use: open
```

Carrying the Return Mark does not improve a roll. It changes what the character
can remember and what a later body can be told.

Carrying the vial does not create a new power. It creates a promise-shaped
resource: something may be placed inside later, but only if the player declares
what it can carry and how it can come home.

## The return

The player may return through a safe route without a roll. The Return Mark then
records that the inherited witness crossed back into the original room.

If the route carries `Flicker`, returning has the same known consequence as
crossing while unstable. The player may accept it or refuse. The Mark does not
override the route's state.

```text
return declared
-> route state consulted
-> player accepts or refuses
-> location changes if accepted
-> inherited objects and traces remain witnessed
-> Rest or continue
```

The room remembers that the player returned. It does not conclude that the
previous visitor did.

## A gentle continuation

At a later Rest, the group may ask:

> What kind of return did the prior visitor intend?

That question can grow into a new body, a remembered message, a damaged route, a
second ecology, or nothing further. The group is not required to solve the
absence in order to honor it.

## Completion test

This slice is complete when a group can:

- discover a prior crossing without a forced backstory;
- distinguish evidence from interpretation;
- carry, leave, or refuse an inherited object;
- preserve the object's location in public memory;
- return without claiming the prior visitor's outcome;
- use the Return Mark as a witness rather than a power-up;
- record the unanswered question for a later session;
- Rest with both the inheritance and the uncertainty intact.

The far side has given us something small enough to carry and large enough to
care about.
