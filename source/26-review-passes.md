# Review Passes

## The purpose of review

Deep Hearth is now large enough that adding more content before testing the
seams would make the garden harder to understand. Review is a form of care: it
finds contradictions before they become physics.

## Pass one: vocabulary

Search every chapter for State, Condition, Pressure, Integrity, Reserve,
Boundary, Refusal, Witness, Trace, Memory, Rest, and Still point. Each use must
match the canonical alpha meaning.

## Pass two: numbers

Run these values through actual examples:

```text
capacities: Body, Sense, Craft, Will
Demand: 8, 12, 16, 20, 24
default Integrity: 3
default Reserve: 3
combat round: 6 seconds
cycle budget: 6
```

Check whether the numbers produce decisions, whether help is worth its cost,
whether failure changes the future, and whether a character can still act after
Reserve reaches zero.

## Pass three: complete loop

Play the full-loop audit from the quick reference. Use one Alchemist, one
Wayfinder, the Threshold Room, one exchange, the Combat Clock, one Hold
Relation, one armed exchange, and Lantern Seed.

Record every point where a player asks:

```text
What can I do?
What will it cost?
What happens if I refuse?
What does the world know?
What can I return to?
```

An unanswered question is a rule or interface gap, not a player failure.

## Pass four: agency and care

Check that no rule:

- decides a private value;
- treats refusal as a malfunction;
- spends an unoffered resource;
- converts defeat into ownership;
- forces a body to accept care;
- makes death the only meaningful ending;
- uses hidden state to contradict witnessed state.

## Pass five: materials

Lay out the table kit. Every token, die, card, thread, container, clock, and
ledger must have one visible role in the current scene. Remove any object that
adds handling burden without computation, memory, or delight.

## Pass six: REPL compatibility

For every compute organ, run the same operation in Magic mode and cardless mode
when both are declared. Check that:

- the input type is explicit;
- the cost is paid once;
- cycle and latency are bounded;
- private and shared scopes remain distinct;
- errors return refusal or unknown rather than invented output;
- the transcript can be witnessed and replayed;
- the organ is optional for a group that does not possess its host materials.

## Pass seven: publication

Check page breaks, table widths, code blocks, printable forms, EPUB navigation,
MIT licensing, and the separation between open Basin mechanics and private
Forgotten Realms content.

The final review question is:

> Can another group enter, change, remember, Rest, return, and extend the world
> without the designer silently supplying its missing physics?
