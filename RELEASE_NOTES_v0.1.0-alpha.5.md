# Deep Hearth 0.1.0 Alpha 5

Deep Hearth Alpha 5 is **The Witnessed Return Alpha** from Basin Game Studios.
It is a technical reference-body closure release, not a Beta release.

Alpha 4 remains available as the historical **Responsive Neighborhood Alpha**:
the release that first made a populated place answer back. Alpha 5 keeps that
bounded Waterdeep slice and makes its most important procedures runnable without
private designer physics.

## The Witnessed Return

Alpha 5 closes the operational loop:

```text
declare
-> quote cost and uncertainty
-> commit or refuse
-> resolve
-> change the owned state
-> witness the consequence
-> Rest or continue
-> return to what changed
```

The release adds authoritative procedures for:

- opposed ties and `STRAINED CONTACT`;
- six-cycle interrupt timing;
- Natural Rest and Somatic Care;
- habitat-specific attention;
- safe-Rest and field land retuning;
- coarse beast away-time with bounded habitat registers;
- population, functional, named, and persistent resident depth;
- source-bound knowledge disclosure;
- owned-register Responsive Neighborhood actions;
- canonical T-Stop mappings for local fiction labels.

## Responsive Neighborhood Closure

The Waterdeep neighborhood now has an Alpha 5 action procedure and default
profiles for buying water, asking the baker, investigating, following rats,
negotiating, organizing, repairing, exposing contamination, refusing, and
leaving. Each profile declares:

```text
owner
trigger
capacity or routine basis
cost and latency
receiving register
outcome
T-Stop
witness
recovery or return path
```

The scene remains bounded. A local action may propagate one declared consequence
across a public witness, shared resource, role, permission, labor, obligation, or
threshold, but the table does not simulate the whole neighborhood.

## Forms and Review

The quick-reference and printable toolkit now include action, knowledge, care,
land-retuning, neighborhood, and beast away-time fields. The authoritative review
passes include a Witnessed Return closure pass covering computation, ownership,
cost, timing, T-Stops, witnesses, recovery, and return.

## Release Boundary

This remains an Alpha technical reference body. The Beta label still requires real
human play reports from real tables. Paper walkthroughs and computation review
can expose contradictions, but they do not replace that gate.

The next deliberate work is to let Gemini review this closure body, then use real
table play to learn which procedures should be promoted, revised, or retired.
